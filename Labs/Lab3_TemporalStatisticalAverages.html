Working with temporal and statistical averages

Laboratory 3, DEDP

1 Objective

Use mean(), std(), and var() to summarize real measurements. Distinguish averages along time from averages across observations, choose the correct matrix dimension, and explain why an average of ratios differs from a ratio of totals.

2 Theoretical aspects

2.1 Statistical mean, variance, and standard deviation

Statistical averages are defined using the probability distribution, rather than a particular measured sequence.

For a continuous random variable A with probability density w_A(x), its statistical mean is

\mu_A=\mathrm{E}\{A\}=\int_{-\infty}^{\infty}x\,w_A(x)\,dx.

Its statistical variance is:

\sigma_A^2=\mathrm{E}\{(A-\mu_A)^2\} =\int_{-\infty}^{\infty}(x-\mu_A)^2w_A(x)\,dx.

The standard deviation is the square root of variance:

\sigma_A=\sqrt{\sigma_A^2}.

For a discrete random variable, replace the integrals by sums.

Note: When we work with data, we cannot compute these integrals directly, since they assume we know the underlying distribution. What we compute in practice, using long vectors of actual data, are temporal averages. If we have a property called ergodicity, temporal averages will converge to the statistical averages, when the number of samples goes to infinity.

2.2 Temporal mean, variance, and standard deviation

Temporal averages are what we compute in practice, e.g. in Matlab, when we have a finite vector of samples.

For a finite vector x[1],\ldots,x[N], its temporal mean is

m = \bar{X} =\frac{1}{N}\sum_{n=1}^{N}x[n].

The temporal variance is:

v = \frac{1}{N-1}\sum_{n=1}^{N}(x[n]-\bar{X})^2

or:

v = \frac{1}{N}\sum_{n=1}^{N}(x[n]-\bar{X})^2

The difference is in the first term, known as the normalization factor, which is either \frac{1}{N-1} or \frac{1}{N}. The choice depends on whether the mean \bar{X} is estimated from the same data or is known a priori:

  • use \frac{1}{N-1} when the mean \bar{X} is estimated from the same data;

  • use \frac{1}{N} when the mean \bar{X} is the true mean, and is known a priori.

The temporal standard deviation is the square root of variance:

s = \sqrt{v}.

For an infinite-length sequence, the temporal averages are defined as a limit of averages over increasingly long intervals.

2.3 Computing averages in Matlab

For a vector, mean() computes the arithmetic mean. var() and std() default to normalization by N-1, whereas var(x,1) and std(x,1) use N:

x = [1, 2, 1, 5, 6, 5, 6, 6, 7, 10, 14, -3];
m = mean(x)
v = var(x)       % denominator N-1
s = std(x)       % square root of var(x)
vN = var(x, 1)   % denominator N
sN = std(x, 1)   % square root of var(x, 1)

For a matrix X, the functions mean(X), std(X), and var(X) operate along the columns by default, giving one result per column.

In order to perform the averages along rows, specify the dimension argument dim=2 (see documentation). For example, for a matrix X of size N-by-M, the following commands compute temporal and ensemble averages:

% mean(X, dim)
mean(X)     % Operate on columns. Produces a 1-by-M vector of means along columns
mean(X, 2)  % Operate on rows. Produces a N-by-1 vector of means along rows
% Same for var()
% Use like this: var(X, normalization, dim)
var(X)         % Uses 1/(N-1), operates on columns
var(X, 1)      % Uses 1/N, operates on columns
var(X, 0, 2)   % Uses 1/(N-1), operates on rows
var(X, 1, 2)   % Uses 1/N, operates on rows
% Same for std()
std(X)         % Uses 1/(N-1), operates on columns
std(X, 1)      % Uses 1/N, operates on columns
std(X, 0, 2)   % Uses 1/(N-1), operates on rows
std(X, 1, 2)   % Uses 1/N, operates on rows

2.4 Loading variables from a file

load() reads variables saved in a .mat file:

D = load('data.mat');   % Store the saved variables in a structure
x = D.x;               % Access the variable named x

load('data.mat');       % Load the variables directly into the Workspace

With an output argument, the variables become fields of a structure, accessed using a dot. Without an output argument, they appear directly in the Workspace and can overwrite variables with the same names. The file must be in the current folder or specified by its path.
